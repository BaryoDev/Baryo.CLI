# Code of Conduct

## The short version

Be decent. Critique code, not people. Assume the person on the other end is trying.

## The longer version

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. It applies in issues, pull requests, discussions, commit messages and
anywhere else the project is being discussed.

Briefly, that means: welcoming and respectful behaviour is expected; harassment,
personal attacks, insults, and publishing anyone's private information are not
acceptable, in any form.

One addition specific to this repository: **code review here is direct.** A review that
says a change is wrong, or that a claim in a pull request does not hold up, is doing its
job. That is not a conduct problem. Directed at a person rather than at the work, it is.

## Reporting

Email arnelirobles@gmail.com. Reports are handled privately. The maintainer may warn,
remove content, or block an account, depending on severity.
